Weighted Consensus Clustering Using Hybrid Bio-Inspired Optimization

About the Project

This research proposes a Weighted Consensus Clustering framework using Hybrid Bio-Inspired Optimization to improve clustering quality and reliability. Multiple clustering algorithms are combined with hybrid optimization techniques to generate improved clustering solutions.

Algorithms Used

Base Clustering Algorithms

- K-Means
- Fuzzy C-Means (FCM)
- Gaussian Mixture Model (GMM)
- Agglomerative Clustering
- Spectral Clustering
- DBSCAN

Hybrid Optimization Techniques

- GA + PSO
- PSO + SA
- GA + GWO
- ACO + PSO

Evaluation Metrics

- Silhouette Score
- Davies–Bouldin Index (DBI)
- Xie–Beni Index (XB)
- C-Index
- McClain–Rao Index

Datasets

The framework was evaluated using six datasets:

- Iris
- Mushroom
- Red Wine Quality
- Life Expectancy (WHO)
- Wholesale Customers
- POL Telecommunications

Objective

The main objective is to improve cluster compactness, minimize cluster overlap, and generate more reliable clustering results through hybrid optimization and weighted consensus clustering.

Research

This repository contains the experimental implementation, datasets, results, and related resources associated with this research.
